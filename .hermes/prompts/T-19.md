# T-19: `--mock` provider + smoke test docs

## Context

Currently there's no way to test the app without a real API key. A `MockProvider` allows running the full agent loop (including tool calls) offline. Smoke docs give a manual checklist for real Termux testing.

## Files

**Create:**
- `src/providers/mock.ts` — MockProvider implementation
- `docs/smoke-test.md` — manual smoke test checklist

**Modify:**

## Implementation details

1. `src/providers/mock.ts`:

```typescript
import type { IProvider, Message, StreamChunk, ProviderCapabilities, ProviderStreamOptions } from '../types.js';

const FIXTURES = {
  simple: [
    { type: 'text', delta: 'Hello! I am the mock provider.' },
    { type: 'done' },
  ],
  toolCall: [
    { type: 'tool_call', id: 'mock_tc_1', name: 'bash', input: { command: 'echo "mock execution"' } },
    { type: 'done' },
  ],
};

export class MockProvider implements IProvider {
  readonly name = 'mock';
  readonly model = 'mock-model';
  readonly capabilities: ProviderCapabilities = {
    streaming: true,
    tools: true,
    vision: false,
    systemPrompt: 'parameter',
  };

  async *stream(
    messages: Message[],
    options?: ProviderStreamOptions,
  ): AsyncIterable<StreamChunk> {
    // Check if last user message mentions "tool" → return toolCall fixture
    const lastUser = [...messages].reverse().find(m => m.role === 'user');
    const fixture = lastUser?.content.toLowerCase().includes('bash')
      ? FIXTURES.toolCall
      : FIXTURES.simple;

    for (const chunk of fixture) {
      yield chunk as StreamChunk;
    }
  }
}
```

2. `src/index.ts`:
- Parse `--mock` flag (meow already supports it)
- When `--mock` is passed, create a `MockProvider` instead of loading from config
- Set `mode: 'agent'` if `--mode agent` is also passed
- Skip config file loading entirely (no API key needed)

3. `src/providers/registry.ts`:
- Add `mock` type to the provider factory so `createProvider` returns `MockProvider` when type='mock'
- Mock provider doesn't need an API key

4. `docs/smoke-test.md`:
Checklist covering:
- Fresh install on Termux: `pkg install nodejs coreutils` → `npm install -g .`
- Basic chat: `a-llmcli --mock` → type a message → "Hello! I am the mock provider."
- Agent mode: `a-llmcli --mock --mode agent` → type "run bash" → tool call → confirm → result
- /clear, /help, /model, /mode commands
- Ctrl+C → restart → crash recovery prompt (T-16)
- Real API: config.yaml with anthropic/openai key → basic chat
- Real API agent mode: type "list files" → bash tool call → confirm → result
- Network kill: disconnect WiFi mid-stream → retry message shown → connection restored → resume
- Code block in response → syntax highlighted (T-18)
