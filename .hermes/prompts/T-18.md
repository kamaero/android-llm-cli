## Implementation details

1. `src/ui/CodeBlock.tsx`:

```typescript
interface CodeBlockProps {
  code: string;
  lang?: string;     // language hint from ```lang
}
```

Logic:
- Use `useState` for highlighted HTML result (or null before loading)
- Use `useEffect` to dynamically import highlight.js:
  ```ts
  useEffect(() => {
    async function load() {
      const hljs = await import('highlight.js/lib/core');
      if (lang && lang !== 'text') {
        try {
          await import(`highlight.js/lib/languages/${lang}`);
          hljs.registerLanguage(lang, ...);
        } catch { /* fall back to auto-detect */ }
      }
      const result = lang 
        ? hljs.highlight(code, { language: lang }).value
        : hljs.highlightAuto(code).value;
      setHighlighted(result);
    }
    load();
  }, [code, lang]);
  ```
- Render: Ink `<Box>` with border, the lang label as `<Text bold>`, and the highlighted code as `<Text>` with ANSI-like coloring
- Since highlight.js returns HTML with `<span class="hljs-...">`, convert to Ink `<Text color="...">` using a simple tokenizer that maps highlight.js class names to Ink colors:
  - `hljs-keyword` → `magenta`
  - `hljs-string` → `green`
  - `hljs-number` → `yellow`
  - `hljs-comment` → `gray` (dim)
  - `hljs-built_in` → `cyan`
  - `hljs-title` → `blue`
  - Everything else → default
- **Performance guard:** If the import takes >200ms on first call, skip highlighting and render plain code (Ink is single-threaded, blocking import makes UI freeze)
- Cache loaded languages in a module-level `Set<string>` to avoid re-importing
